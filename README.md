# app

풀스택 모노레포: React 19 + Stackflow SPA(`apps/web`), Cloudflare Workers +
D1 위의 Hono + oRPC API(`apps/api`), 그리고 둘이 공유하는 타입 계약
(`packages/contract`). Bun 워크스페이스 + Turborepo이고, Biome, Steiger, knip,
테스트를 pre-commit 훅이 강제합니다.

## 프로젝트 맥락

이 프로젝트는 다른 사람의 관점이 궁금한 20대 독자가 시간과 장소의 제약 없이
각자의 속도로 독서 경험을 나누는 방법을 탐색합니다. 실물 책을 주고받는
교환독서는 만남과 일정 조율이 어려워 지속하기 어렵다는 문제에서 출발합니다.

기획의 핵심은 비동기적 연결, 완독이나 즉각적인 응답을 요구하지 않는 참여,
그리고 독자 자신의 해석을 유지하면서 다른 관점으로 생각을 확장하는 것입니다.
독자가 타인의 감상을 접하는 시점과 교류의 강도를 직접 선택할 수 있어야 합니다.

서비스는 모바일 화면과 터치 조작만을 대상으로 설계합니다. 화면 이동은
Stackflow 액티비티의 스택과 브라우저 히스토리를 사용하며, 독서 중 책갈피와
감상을 확인한 뒤 이전 맥락으로 돌아오는 흐름을 고려합니다. 데스크톱 전용
레이아웃이나 별도의 데스크톱 사용 흐름은 기획 범위에 포함하지 않습니다.

아이데이션에서 선정한 세 가지 솔루션은 다음과 같습니다. 아직 구현이나 검증이
완료된 기능이 아니라 앞으로 구체화하고 평가할 아이디어입니다.

- **페이지 팝업 책갈피:** 독자가 책갈피를 눌러 이전 독자가 해당 페이지에서
  멈춘 이유나 한 줄 감상을 확인합니다.
- **비동기 알림:** 새로운 의견을 즉시 알리는 대신 독자가 책을 다시 펼쳤을 때
  알려 주어 자신의 속도로 확인하고 교류하도록 돕습니다.
- **질문형 여백 템플릿:** 독자가 선택할 수 있는 질문과 책 내용 및 감상 맥락에
  기반한 AI 질문 후보로 생각 정리를 돕습니다. 답변은 필수가 아니며, 질문이
  특정 해석을 유도하거나 감상의 자유를 제한하는지 사용자 평가가 필요합니다.

## 빠른 시작

```bash
bun run setup   # 설치, 로컬 D1 생성, 데모 데이터 시드
bun run dev     # http://localhost:3000  (API 문서: /api/docs)
```

Cloudflare에 배포(Worker 하나가 앱과 API를 함께 제공):

```bash
bunx wrangler login   # 최초 1회
bun run deploy        # Worker `hci`, D1 `hci-db` (apps/api/wrangler.jsonc)
```

플레이스홀더입니다. 전환 절차는
[`.claude/skills/start-project/SKILL.md`](.claude/skills/start-project/SKILL.md)
